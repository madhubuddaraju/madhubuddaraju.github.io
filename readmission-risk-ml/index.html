How it was built

Every step runs in CI against a real MySQL 8 database
1 · IngestChecksum-verified CSV into MySQL raw tables
2 · FeaturesPySpark windows over patient history, ICD-9 groups
3 · SplitBy patient hash, so nobody is in train and test
4 · TrainSpark LR, LightGBM, PyTorch embeddings net
5 · EvaluateCalibration, bootstrap CIs, fairness, SHAP
6 · ServeFastAPI + MySQL history lookup, MLflow registry
Data: UCI "Diabetes 130-US hospitals, 1999-2008" (Strack et al., 2014), CC BY 4.0. Results are on held-out test patients; decisions were made on validation patients only.
